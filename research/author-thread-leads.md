Petunjuk untuk diverifikasi: https://nitter.cf/ibamarief . Ini mirror profil dari indeks pencarian, dapat usang; cari permalink dan sumber primer bila tersedia.

Ia menyebut graph berlapis dengan ontologi sesuai domain; contoh negasi memperlihatkan keyword matching dapat salah menganggap seseorang hadir pada rapat. Ia menyebut ETL berbasis event dan materialized views PostgreSQL sebagai pilihan untuk beberapa kasus. Ini deskripsi publik, bukan verifikasi source code internal.

Post lain membahas inspeksi sitasi, review multiagent, trade-off latensi, dan kemungkinan mengarahkan pertanyaan sederhana ke graph lookup. Verifikasi sebelum memakai klaim angka atau model. Buat keputusan MVP lokal sederhana, bukan tiruan seluruh produk.
